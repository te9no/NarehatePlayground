00 / 対象版

このガイドを使う基板

中央下に4穴が千鳥に並ぶLED位置（U4〜U7）があり、R11が表面実装の0805、R12がリード抵抗の基板が対象です。左右各30キー、すべて1uです。

SMD LEDが表面に実装済みの60キー基板には、SMD LED版の組み立て手順・部品表・UF2を使います。58キー用はファームウェア一覧で基板のLED種別に合わせて選んでください。

各章の3Dは旧基板で手の動きや挿入方向を見るための参考図です。取り付け位置はR3のシルクと本文のR3図で確認します。

01 / 準備

部品を分けて、低いものから実装

R3部品表（CSV）で参照番号と数量を確認します。表面PCBAは17点。手実装欄は145項目（J2の書き込み端子とJ3の子基板接続位置を含む）です。

別に、組立済みの昇圧基板、MXスイッチと1uキーキャップ各60個、プレート、ケース、単3形NiMH充電池2本を用意します。LEDは秋月 OST4ML5B32A（117058）を4個使います。

温調はんだごて、熱風リフロー設備、適合するはんだペースト、フラックス、はんだ、吸い取り線、ニッパー、ピンセット、テスター、拡大鏡、基板保持具を用意します。初回書き込みにはST-LinkとSWD配線が必要です。

  1. PCBAの目視確認
  2. マイコン・USB端子のリフロー（片面ずつ）
  3. ダイオード・抵抗・コンデンサ・砲弾型LED
  4. ソケット・昇圧基板
  5. スイッチ・電池端子
  6. 無通電検査 → USB確認 → ファームウェア → 電池確認
  7. プレート・キー・カバー・ケース
組み立て・抵抗測定・はんだ修正は電池、USB、ST-Linkをすべて外して行います。電池は最後まで入れずに進めます。
02 / PCBA

表面の小部品を確認

PCBAはすべて表面です。以下がそろっていることをBOMと照合します。

参照番号担当
U2・U3LDO・電源切替
Q1・Q2LED電源・電池電源制御
D61電源ダイオード
R3〜R5電源周辺抵抗
C3〜C11電源・LED周辺コンデンサ

浮いた端子、隣接ピンのはんだブリッジ、部品欠落を拡大して確認します。

U4〜U7とR11は手実装します。R11は10kΩ・1%・0805（C17414）。他の抵抗や電池金具を付ける前にこてで取り付けます。
03 / リフロー

マイコンとUSB端子をリフロー

J1：USB-C / TYPE-C-31-M-12

USB端子は裏面。基板端へ口を向け、シルクとパッドに合わせて固定します。ランドにペーストを塗布し、ピンセットで位置を合わせてリフローします。シェルの固定足は接合を確認し、必要に応じてこてで仕上げます。拡大してピン間ブリッジを確認。CC1/CC2用のR1/R2も両方必要です。

U1：MDBT50Q-1MV2

表面中央上端に実装します。モジュールのアンテナ側を基板の上端へ向け、ランドに正確に合わせます。ペーストを塗布し、端子列のズレを対向する角で確認してからリフローします。冷却してから接合と隣接端子の短絡を検査します。U1とJ1は別々の面なので、片面ずつ保持して作業します。加熱条件は各部品とペーストの指定に合わせ、周囲の樹脂部品を保護します。冷えるまで部品を動かさないでください。

04 / ダイオード

1N4148を60本。帯側を毎回確認

D1〜D60は表面から挿し、裏面ではんだ付けします。リード間隔は7.62mm。ガラス本体に力を掛けず、足を曲げて数本ずつ固定します。

黒い帯がカソード（K）。R3図の赤丸がパッド1＝帯側です。中央の左右で向きが変わるため、全部を同じ方向にそろえません。下側の縦配置も個別に確認します。

  1. シルクの帯表示と補助図のパッド1を合わせる。
  2. 片足を仮止めして位置を確認。
  3. もう片足をはんだ付けし、余ったリードを切る。下の写真の1〜3は昇圧基板に当たるので、はんだの山から突き出た足だけをできるだけ短く切ります。
  4. 隣の部品・電池端子へ切断面が触れないことを確認。

ダイオードモードは、はんだ前の単体部品で向きを確かめると分かりやすくなります。実装後の測定は周囲の回路によって読み値が変わります。

中央の縦列はUSB側からR6、R8、R7、電源スイッチ、R9、R10の順。下端のR11・R12は次の工程で確認します。値の取り違えを防ぐため、取り付け前にテスターで確認します。

05b / 砲弾型LED

LEDの向きを合わせ、はんだ付け前に点灯を確認する

  1. 仮挿し。 抵抗とマイコン用コンデンサ（C1＝4.7µF、C2＝1µF）を取り付けます。LED周辺はR8が100Ω、R11（0805）とR12（リード）が各10kΩです。USBと電池を外し、LEDの足を根元から少し離れた位置で交互に前後へ曲げます。U4〜U7の1番印にDINを合わせ、4個とも表面から差し込みます。まだ足は切らず、はんだ付けもしません。
  2. USBで点灯確認。 マイコンにOST・60キー用の起動アニメーション付きファームを書き込んだ状態で行います。足同士が触れていないことと電源の短絡がないことを確認し、電池を抜いたままUSBを接続します。起動時に4灯へ順に光が流れるのを確認してください。途中で消える場合はUSBを抜き、足の向きと穴での接触を確かめてから試し直します。
  3. 本付け。 USBを抜き、樹脂の底を基板から3mm以上浮かせます。4個の高さをそろえて片足ずつ仮止めし、ダイオードの足と触れていないことを横から確かめたら、裏面で残りをはんだ付けして余った足を切ります。
06 / ソケット

Kailhソケットを裏面へ

MX1〜MX60：Kailh CPG151101S11

ソケットは裏面。各フットプリントの樹脂逃げ穴・パッド位置に合わせます。部品ごとの向きはその位置の基板シルク・実パッドで確認します。片側だけ固定して密着を確認し、反対側をはんだ付けします。スイッチを挿すときはソケットを裏から支え、接点に曲がった足を押し込まないようにします。

07 / 昇圧基板

昇圧基板を裏面に取り付ける

昇圧基板を仮置きし、切りそろえたダイオードの足に当たらず、接続パッドが浮かないことを横から確認します。ピンヘッダーは使わず、対応するパッド同士を直接はんだ付けします。

J3番号接続先
1GND
2USB_VBUS
3BAT_SENSE → マイコンADC
4昇圧出力
5BAT_SWITCHED（スイッチ後の電池入力）

パッド番号とネット名で向きを照合し、1か所を仮止めして位置・浮き・他部品との接触を確認。その後、残りを接合します。左右を写真だけで判断せず、裏表を区別してください。

08 / スイッチ・電池端子

リセットボタン・電源スイッチ・電池端子を取り付ける

SW1とSW2の向き

  1. SW1は押しボタンを基板の表に向け、4本の足をSW1の穴に合わせて差し込みます。ボタンがまっすぐ押せることを確認し、裏面ではんだ付けします。
  2. SW2（SS-12F16G6）は、黒いつまみが表に出るように中央の白枠に合わせて取り付けます。USBと電池を外したまま、導通計でON側は端子2–3、OFF側は端子1–2がつながることを確認します。

4個の共通端子を、電池が収まる向きに固定する

BC1〜BC4にはすべて同じ電池端子（MY-AA-07 / C2979180）を使います。電池1本につき2個を一組にし、両端の接点を内側に向けて仮止めします。写真のように電池を両端から受ける向きになっていることを確認し、電池を外した状態で裏面からはんだ付けします。

表面・上端を上に見る：左の電池は 上が＋ ／ 右の電池は 下が＋

左右の電池中心間隔は22mmです。電池を入れる向きは、基板の＋・−表示と下表で確認します。

端子位置・ネット
BC1左上 / BAT_RAW / 電池＋
BC2左下 / BAT_MID / 電池−
BC3右上 / GND / 電池−
BC4右下 / BAT_MID / 電池＋
旧基板では金具同士が接触して電池が発熱しました。新しい配置でも、金具の張り出し・しなり・ケースによる押し込みを実物で確認します。接触している状態で電池を入れないでください。

BC2–BC4は直列接続の中点なので、電気的に導通するのが正しい状態です。一方、BC1–BC3は電池全体の＋/−。ここが安定して約0.9Ωなどの低抵抗になる場合は通電せず、短絡を調べます。まずテスターのリード同士を当てた抵抗も確認してください。

抵抗値はコンデンサの充電や半導体の影響を受けます。「導通ブザーが一瞬鳴る」だけで合否を決めません。OFF状態の測定だけではスイッチ後の短絡を見落とすため、電池・USBを外したままON側も確認します。

09 / 通電確認

USBと電池を段階的に確認

導通チェッカーを開くと旧SMD版の測定図が表示されます。R3ではプローブを当てる前に実基板の参照番号・パッドを照合します。旧版の図はR3のLED周辺には使えません。無通電で行う測定と、通電して行うキー入力試験を区別してください。

  1. すべてのはんだと切断したリードを拡大確認。BAT_RAW–GND、SYS_VDD–GND、USB_VBUS–GNDに持続する低抵抗短絡がないか調べます。
  2. 電池を抜いたままUSBを接続。USB_VBUSは約5V、SYS_VDDは約3.3Vが目安です。SWD J2の1番はSYS_VDD、4番はGNDです。5VをJ2の1番へ入れないでください。
  3. ファームウェアを書き込み、USBキー入力とLED表示を確認してからUSBを外します。
  4. 金具の接触がなく極性が正しいことを再確認し、NiMH単3を2本装着。可能なら最初は電流制限できる電源で電池系を確認します。
  5. SW2をONにして無線でのキー入力を確認。発熱・におい・異常があればすぐ切り離し、再通電せず原因を確認します。

SW2は電池側の電源を制御します。USB接続中はOFFでも動作し、NiMHをUSBから充電する機能はありません。電池は取り外して対応充電器で充電します。

LEDは常時点灯しません。正常でも普段は消えています。Fn長押し時の表示で確認します。
10 / 書き込み

初回はST-Link、通常更新はUF2

J2 SWD信号接続の考え方
1SYS_VDD（3.3V）対応ライターの電圧参照。ST-Linkの3.3V出力と同じとは限らない
2SWDIOST-Link SWDIO
3SWDCLKST-Link SWCLK
4GNDST-Link GND
5RESET_N対応する場合はNRST。SWIMではない

ST-Link互換機は端子配列が異なるため、本体表記と仕様で確認します。基板の給電元を一つにし、USB給電とライターの3.3V出力を安易に並列接続しません。

初回ブートローダー導入（既存設定を消去）

Stokerjack_bootloader_SWD.hexを使います。OpenOCDで書き込む場合の設定例です。mass_eraseは既存アプリとペアリング設定を消去します。必要なら先にバックアップし、ダウンロードしたHEXと設定ファイルを同じ作業フォルダーに保存し、そのフォルダーで実行します。

source [find interface/stlink.cfg]
source [find target/nordic/nrf52.cfg]
adapter speed 100
init
reset halt
nrf5 mass_erase
program Stokerjack_bootloader_SWD.hex verify
reset run
shutdown

OpenOCDのバージョンによってtargetファイルの位置が異なります。設定ファイルを保存し、対応するOpenOCDで openocd -f install-stokerjack.cfg を実行。verify成功を確認します。ブートローダーが既に動作する基板では、この工程を繰り返す必要はありません。

通常の書き込み

  1. データ通信対応USBケーブルでPCへ接続。
  2. RESETを500ms以内に2回押す。
  3. 「STOKERJACK」ドライブが現れたら、OST・60キー・DYA Studio版UF2（Stokerjack_OST_1M_Studio_CDC_Debug_60.uf2）をコピー。
  4. 再起動後、USBキーボードとして認識することを確認。

58キー基板にはこの60キー用UF2を使わないでください。旧アドレス0開始SWDアプリを書き込むとブートローダーを上書きします。

ソースから作る場合はGitHub Actions の Build Stokerjack Studio 60で Run workflow を選びます。成功した実行の Artifacts からZIPを展開し、中のUF2を同じ手順でコピーします。

USBで入力と4灯を確認する

起動すると4灯に左から右へ光が流れます。メモ帳でAを押し、小文字のaが入ることを確認してください（Caps Lockがオフのとき）。次の操作は初期USキーマップでの位置です。

操作LEDの読み方
最下段の左から5番目か8番目を長押し（Fn）紫の1灯から電池残量へ切り替わります。左から1〜4灯で約25%刻み。赤は25%以下、橙は50%以下、緑はそれ以上。紫4灯は残量取得前です。
Fnを押しながら通常の /（右Shiftの左）USB選択時は白4灯。無線接続時は選択した番号の位置が青、未接続なら橙。5番は両端が光ります。
最下段の左から4番目を長押し（Num）左の2灯が橙。接続先選択レイヤーでは左の3灯が青緑です。

電池で無線接続を試す

  1. 電池端子の検査後、USBを外してSW2をONにします。
  2. Aのすぐ左のキーを押し続け、最上段の数字1〜5で接続先を選びます。初めて使う端末には空き番号を選びます。
  3. 端末の設定でワイヤレス機器の追加を選び、「Stokerjack」を追加し、メモ帳で文字を入力します。Fn＋ / で接続先も確認できます。

DYA Studioと書き込みモード

USBでPCに接続し、DYA StudioでStudio用のシリアルポートを選びます。ロックは常時解除です。もう一方はデバッグログ用で、1200 bpsで開いて閉じるとUF2書き込みモードに入ります。ポートを開けないときは、そのポートを使っているシリアルモニターを閉じてください。

11 / 仕上げ

プレート、キー、カバーを取り付ける

プレートとケースを仮組みします。中央下のLEDは樹脂底を3mm以上浮かせるため、カバーを使う場合は完成状態で高さを測ります。

  1. 電池・USBを外し、プレートのダイオード・端子・ねじ頭との干渉を確認。
  2. スイッチの足がまっすぐか確認して、プレートとソケットへ取り付ける。
  3. 全キーを入力テストし、動かないキーはスイッチ足・ソケット・ダイオードを確認。
  4. キーキャップとケースを取り付ける。アンテナ周辺を金属で覆わない。
  5. 必要に応じてアクリル天板を取り付ける。LED、抵抗、電池金具に力が掛からず、SW2を操作できることを確認します。
12 / 確認表

組み立て確認表

入力はできるのにLEDが光らない

Fnを長押しして、LEDを表示させます。4灯とも消えたままなら、まずOST・60キー用UF2のファイル名を確認します。USBと電池を外し、U4の1番（DIN）からR8・R11・R12のLED_DIN側までを導通確認します。抵抗をまたぐ測定では抵抗値が出ます。途中のLEDから先だけ消えているなら、最後に光ったLEDの4番から次のLEDの1番までの接合を調べます。

USBでは入力できるのに電池では起動しない

電池を外し、BC2–BC4の直列接続とSW2の切り替わりを確認します。次に昇圧基板のJ3端子1（GND）、4（昇圧出力）、5（スイッチ後の入力）の順序を照合します。短絡検査が済んだら電池だけで起動し、テスターを直流電圧レンジにしてJ2の1–4間に約3.3Vがあるか確認します。

キーが反応しないとき

給電を切ってから、スイッチ足の曲がり、ソケットの接合、ダイオードの向きとはんだ付けを確認します。同じ行・列のキーがまとめて反応しない場合は、ROW/COLの共通配線も確認してください。

導通チェッカーの配線試験と入力試験で切り分けられます。GPIO：Dなしモードは、対応ファームウェアが動作している基板で指定のCOLとROWを1組だけ接続する試験です。通電中にテスターの導通・抵抗モードを使わないでください。

チェック状態はこのブラウザにのみ保存します。実物の合否を自動判定するものではありません。
