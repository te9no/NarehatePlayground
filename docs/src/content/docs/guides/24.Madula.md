---
title: 🧩 Madula ビルドガイド
---

Madulaは、左右のCornixと組み合わせて使う中央ユニットです。中央の3キーに加え、トラックボール、トラックポイント、IQSトラックパッドのいずれかを搭載できます。PCとはMadulaを接続し、左右のCornixはMadulaの子機として動作します。

```text
Cornix 左（子機） ──無線──┐
                        ├─ Madula（親機） ──USBまたはBluetooth── PC
Cornix 右（子機） ──無線──┘
```

## 購入前チェック

| 確認項目 | 必要なもの・注意点 |
| --- | --- |
| 対象 | Madula本体の組み立てガイド。左右のCornixは別途必要 |
| ポインティングモジュール | PMW3610トラックボール／ADS1220 LPPSトラックポイント／IQS9151トラックパッドから1種類を選択 |
| スイッチ・キーキャップ | 中央3キーはULPキースイッチ。対応するキーキャップを3個用意 |
| 電池 | 商品ページまたは同梱案内で指定された充電池を使用。種類や極性を推測して通電しない |
| ファームウェア | Madula、左Cornix、右Cornixの3台に、それぞれ対応するUF2が必要 |

購入した構成によって部品や実装済みの範囲が異なる場合があります。手元の同梱表と基板の版が本ページと異なる場合は、同梱案内を優先してください。

## 作業を始める前に

1. はんだ付けやFFCケーブルの抜き差しは、USBと電池を外して行います。電源スイッチをOFFにするだけでは作業しないでください。
2. 部品の取り付け面・向き・極性を、基板の印字と写真の両方で確認します。
3. RGB LEDやFFCコネクタなど、実装済みの小型部品へ追加ではんだを当てないでください。
4. 通電前に、はんだのブリッジ、切り残したリード線、金属部品との接触がないか確認します。

3台へ書くファイルは、搭載するポインティングモジュールを選ぶだけで確認できる[**CornixTP・Madula ファームウェアガイド**](../../cornix-firmware/)にまとめています。

## 部品の確認

写真の構成では、次の部品を使用します。

| 名前 | 数 | 備考 |
| --- | ---: | --- |
| MadulaメインPCB | 1 | XIAO、電源スイッチ、電池端子を実装 |
| 3キーPCB | 1 | ULPキースイッチを実装 |
| Seeed Studio XIAO nRF52840 | 1 | Madulaの親機 |
| ULPキースイッチ | 3 | 中央3キー用 |
| スライドスイッチ | 1 | 電源用 |
| 電池端子 | 1組 | ばね側と平板側 |
| 基板接続用のピン・コネクタ | 1組 | 2枚のPCBを接続 |
| ポインティングモジュール | 1 | 購入した構成により異なる |
| FFCケーブル | 1 | モジュール接続用 |

このほか、はんだごて、はんだ、ピンセット、ニッパー、絶縁に使う付属テープまたは同等品を用意します。

## 1. XIAOを取り付ける

XIAOのUSB Type-Cコネクタが、メインPCBの外周側を向くように置きます。基板の輪郭と写真を照合し、表裏を間違えないでください。

![MadulaメインPCBにXIAOを配置した状態](Madula/01-xiao-placement.jpg)

対角の2か所を仮止めし、XIAOが基板に対して平行で、パッドの位置がそろっていることを確認します。位置を直す必要がある場合は、この段階で行います。問題がなければ、すべてのキャスタレーションをはんだ付けします。

![XIAOのキャスタレーションをはんだ付けした状態](Madula/02-xiao-solder-joints.jpg)

基板を裏返し、XIAOの向きと取り付け位置をもう一度確認します。横から見て浮きや傾きがなく、隣のパッドとのブリッジがないことを確認してください。

![取り付け後のXIAOを部品面から確認](Madula/07-controller-assembled.jpg)
![XIAOとメインPCBの高さを横から確認](Madula/08-controller-clearance.jpg)

## 2. メインPCBの実装済み部品を確認する

RGB LEDとFFCコネクタが実装済みの場合は、追加のはんだ付けは不要です。コネクタのラッチが欠けていないこと、LEDや周囲の小型部品がずれていないことを目視します。

![MadulaメインPCBのRGB LEDとFFCコネクタ](Madula/03-main-pcb-led-ffc.jpg)

## 3. 3キー基板にULPキースイッチを取り付ける

3個のULPキースイッチを、基板の印字に合わせて置きます。各スイッチが基板に密着し、端子がパッドの上にあることを確認してください。

![3キーPCBにULPキースイッチを配置した状態](Madula/04-ulp-switches-placement.jpg)

ULPキースイッチを押さえながら片側を仮止めします。浮きがないことを確認してから、反対側をはんだ付けします。最後に仮止め側も十分にはんだをなじませます。

![3キーPCBのULPキースイッチをはんだ付け](Madula/05-ulp-switches-soldering.jpg)

基板を裏返し、各ULPキースイッチの背面中央にあるスイッチパッドをはんだ付けします。3個とも中央のパッドにはんだが十分になじんでいることを確認してください。

![3キーPCB背面中央のULPキースイッチパッドをはんだ付け](Madula/06-ulp-switch-center-pads.jpg)

## 4. 電源スイッチを取り付ける

スライドスイッチをメインPCBの外形と印字に合わせて差し込み、基板へ密着させます。1か所を仮止めし、スイッチが傾いていないことと、つまみが無理なく動くことを確認してから残りをはんだ付けします。

![Madulaの電源スイッチ実装位置](Madula/09-power-switch.jpg)

## 5. 基板接続用のピンを取り付ける

> **この段階では、基板接続用のピンをメインPCB側だけにはんだ付けします。3キーPCB側は、位置合わせに使うだけではんだ付けしないでください。両方のPCBへ固定すると、次の工程で電池端子を取り付けられなくなります。**

メインPCBへ基板接続用のピンやコネクタを、写真と基板の印字に合わせて取り付けます。

![MadulaメインPCBに基板接続用ピンを配置](Madula/10-board-headers.jpg)

はんだ付けする前に2枚のPCBを仮に合わせ、ピンが穴へまっすぐ入ることと、基板同士が平行になることを確認します。3キーPCBは位置決め治具として使い、メインPCB側のピンを仮止めして位置を調整してから、メインPCB側の残りだけをはんだ付けします。確認後、3キーPCBはいったん取り外して電池端子の工程へ進みます。

![MadulaのメインPCBと3キーPCBを接続前に確認](Madula/11-board-parts-overview.jpg)

## 6. 電池端子を取り付ける

電池端子の下に、カプトンテープやビニールテープなどを貼って絶縁します。ばね側と平板側を、基板の印字と写真に合わせて取り付けてください。端子の金属部分が、周囲のパッドや部品へ触れないことを確認します。

![ばね側の電池端子と絶縁材](Madula/12-battery-spring-terminal.jpg)
![平板側の電池端子と絶縁材](Madula/13-battery-flat-terminal.jpg)

両方の端子をはんだ付けしたら、端子が同じ軸上にあり、電池を斜めに押し付ける状態になっていないことを確認します。この時点ではまだ電池を入れません。

![Madulaの電池端子を取り付けた状態](Madula/14-battery-terminals-installed.jpg)

## 7. 2枚の基板を組み合わせる

接続ピンと固定位置をそろえ、メインPCBと3キーPCBをゆっくり合わせます。入りにくい場合は力をかけず、ピンの曲がりや位置ずれを確認してください。

横から見て、2枚の基板が平行で、XIAOや電池端子が別の基板へ接触していないことを確認します。

![組み合わせたMadulaの基板を横から確認](Madula/15-board-stack.jpg)

## 8. ポインティングモジュールを接続する

1. USBと電池が外れていることを確認します。
2. FFCコネクタのラッチを開きます。
3. ケーブルを斜めにせず、奥までまっすぐ差し込みます。
4. ラッチを閉じ、左右の差し込み量が同じことを確認します。

FFCケーブルの接点面は、基板の版やモジュールで異なる場合があります。写真だけで推測せず、基板の印字と購入したモジュールの案内に従ってください。抜き差しするときに、ケーブルだけを強く引っ張らないでください。

## 9. 通電前の最終確認

- XIAOの全パッドにはんだ不良やブリッジがない
- 3個のULPキースイッチが基板へ密着している
- 電源スイッチが滑らかに動く
- 電池端子の向きと絶縁が正しい
- 2枚の基板が平行で、部品同士が接触していない
- FFCケーブルがまっすぐ入り、ラッチが閉じている
- 基板上に切ったリード線やはんだくずが残っていない

異常な発熱や異臭があった場合は、すぐにUSBと電池を外してください。

## 10. ファームウェアを書き込む

Madulaに搭載したポインティングモジュールと同じファイルを選びます。異なるモジュール用のファイルでは、キーが動いてもポインターが動作しません。

| Madulaの構成 | Madulaへ書くファイル |
| --- | --- |
| PMW3610トラックボール | [`madula_trackball.uf2`](https://github.com/te9no/zmk-keyboard-cornix/raw/refs/heads/main/firmware/zmk-keyboard-cornix/main/madula_trackball.uf2) |
| ADS1220 LPPSトラックポイント | [`madula_trackpoint.uf2`](https://github.com/te9no/zmk-keyboard-cornix/raw/refs/heads/main/firmware/zmk-keyboard-cornix/main/madula_trackpoint.uf2) |
| IQS9151トラックパッド | [`madula_iqs.uf2`](https://github.com/te9no/zmk-keyboard-cornix/raw/refs/heads/main/firmware/zmk-keyboard-cornix/main/madula_iqs.uf2) |

左右のCornixには、それぞれ次のファイルを書き込みます。

| 書き込み先 | 通常使用するファイル |
| --- | --- |
| 左Cornix | [`cornix_left_production.uf2`](https://github.com/te9no/zmk-keyboard-cornix/raw/refs/heads/main/firmware/zmk-keyboard-cornix/main/cornix_left_production.uf2) |
| 右Cornix | [`cornix_right_production.uf2`](https://github.com/te9no/zmk-keyboard-cornix/raw/refs/heads/main/firmware/zmk-keyboard-cornix/main/cornix_right_production.uf2) |

ファームウェアは[zmk-keyboard-cornix](https://github.com/te9no/zmk-keyboard-cornix)の配布案内から、3台分を同じ版で用意してください。ファイルの取得方法やUF2の基本操作は、[ファームウェア取り扱いガイド](../90firmwareguide/)も参照してください。

1. 書き込む機器を1台だけPCへUSB接続します。
2. XIAOのRESETボタンを素早く2回押し、書き込み用ドライブを表示します。
3. 対応するUF2を1ファイルだけコピーし、自動再起動を待ちます。
4. Madula、左Cornix、右Cornixの順に、3台へそれぞれ対応するファイルを書き込みます。

通常の書き込みで、名前に `reset` が含まれる復旧用ファイルを先に使う必要はありません。

## 11. 初回接続と動作確認

1. 3台の電源を入れ直し、MadulaをPCへUSB接続します。
2. 左右Cornixのすべてのキーが入力できることを確認します。
3. Madula中央の3キーを確認します。
4. ポインター移動、クリック、スクロールなど、選んだモジュールの操作を確認します。
5. USBで問題がなければ、PCのBluetooth設定からMadulaをペアリングします。左右CornixをPCへ個別にペアリングする必要はありません。

DYA Studioで設定する場合も、MadulaをUSB接続してStudio用のシリアルポートを選びます。

## 動かないときの確認

| 症状 | 確認・対処 |
| --- | --- |
| RESETを2回押してもドライブが出ない | データ通信対応のUSBケーブルか確認し、PC本体のUSBポートへ直接接続してやり直す |
| 左右の片側だけ入力できない | 該当側の電源と、左右に書いた `production` ファイルを確認する |
| 左右は動くが中央3キーが動かない | ULPキースイッチの浮き・はんだ付けと、Madula用ファームウェアを確認する |
| キーは動くがポインターが動かない | 搭載モジュールとMadula用UF2の対応を確認。FFCを確認するときはUSBと電池を外す |
| USBでは動くがBluetoothでは動かない | PC側の古い登録、選択中のBluetoothプロファイル、Madulaの給電を確認する |
| Madulaと左右が接続しない | 3台が同じ配布版の通常ファームウェアか確認し、すべての電源を入れ直す |

通常の確認で直らない場合に限り、Madulaへ [`madula_split_bond_reset.uf2`](https://github.com/te9no/zmk-keyboard-cornix/raw/refs/heads/main/firmware/zmk-keyboard-cornix/main/madula_split_bond_reset.uf2) を書き込むと、PCとの接続情報を残したまま左右Cornixとの接続情報を消去できます。処理後は必ず、搭載モジュールに合う通常版 `madula_*.uf2` を書き戻してください。

[`madula_factory_settings_reset.uf2`](https://github.com/te9no/zmk-keyboard-cornix/raw/refs/heads/main/firmware/zmk-keyboard-cornix/main/madula_factory_settings_reset.uf2) は、PCとの接続を含む保存設定を消す深い復旧用です。設定が失われるため、通常の更新や最初の切り分けには使いません。使用後は通常版を書き戻し、PC側の古い登録を削除して再ペアリングします。
