## RMKファームウェア

サイト掲載製品にはRMK版もあります。ZMK版とは対応機能・設定方法・移行手順が異なるため、使用するリポジトリのREADMEを先に確認してください。

### CornixTP

- [rmk-config-cornixTP](https://github.com/te9no/rmk-config-cornixTP) — Cornix左右とTPS43トラックパッド付き中央機のRMKファームウェア。Vialによる割り当て編集に対応します。
- [ダウンロード](https://github.com/te9no/rmk-config-cornixTP/releases) · [導入・配線・Vial](https://github.com/te9no/rmk-config-cornixTP/blob/HEAD/docs/cornix-tp.md) · [移行上の注意](https://github.com/te9no/rmk-config-cornixTP/blob/HEAD/docs/release-notes.md)

配布元ではキー入力とトラックパッドの基本操作を確認済みですが、Vial編集の再起動後の保持、BLEホスト／Vial、長時間・電池駆動は未検証と案内されています。最新の検証状況はREADMEを参照してください。

### Madula

- [rmk-keyboard-madula](https://github.com/te9no/rmk-keyboard-madula) — Cornix左右とMadulaを組み合わせるRMKファームウェア。LPPS、PMW3610トラックボール、IQS9151に対応する構成があります。
- [ダウンロード](https://github.com/te9no/rmk-keyboard-madula/releases) · [導入・移行の準備](https://github.com/te9no/rmk-keyboard-madula#はじめに)

`v0.1.0-rc.*`はプレリリースです。モジュールごとの配布対象と検証状況を確認してください。

### MeKaBu（開発用）

- [rmk-config-MKB2](https://github.com/te9no/rmk-config-MKB2) — MeKaBu向けのRMK実装。READMEはソースからのビルド手順が中心です。導入前に、手元の構成への対応と配布・検証状況を確認してください。

**CornixTP・Madulaの移行に注意：** 親機と左右の3台を、各配布元が指定するRMKファームウェアに揃えます。ZMKの子機とは接続できません。また、RMKへの移行は旧SoftDevice領域を上書きし、ZMKへ戻す際に復旧が必要になる場合があります。通常のZMK更新と同じ手順で進めず、配布元の移行案内と復旧手段を確認してください。

## 便利ツール・サイト

### ZMK Helper Android

[ZMKHelperAndroid](https://github.com/te9no/ZMKHelperAndroid) — Androidからファームウェアの取得・書き込みを行うアプリ。APKと対応機器、導入手順はREADMEを参照してください。

### ZMK Shield Fleet

[zmk-shield-fleet](https://github.com/te9no/zmk-shield-fleet) — 複数のキーボードにまたがる変更と検証状況を管理するツール。[ダッシュボード](https://te9no.github.io/zmk-shield-fleet/)から、各製品の対応状況を確認できます。

### Narehate Playground

[NarehatePlayground](https://github.com/te9no/NarehatePlayground) — このサイトのソースコード。ビルドガイドや製品選びのページを管理しています。

配列エディターの[Forma](https://klemodern.netlify.app/)は利用ページを案内しています。公開ソースの所在を確認できていないため、リポジトリのリンクは掲載していません。

## ファイルを取得する前に

1. **機種・基板・モジュール構成を合わせる。** 同じリポジトリに複数の構成が含まれる場合があります。
2. **READMEで対象ブランチを確認する。** 開発用ブランチと通常配布用のファイルを混同しないでください。
3. **ビルド成功と実機確認を区別する。** 新しい更新日時だけで、手元の構成に対応しているとは限りません。
4. **配布方法を確認する。** ファイルはREADMEで案内されている場所から取得します。GitHub Actionsの成果物は保存期限がある場合があります。

書き込みの基本操作は[ファームウェアガイド](../90firmwareguide/)を参照してください。
