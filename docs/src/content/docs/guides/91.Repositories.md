Narehate Playgroundで紹介している製品・ツールを中心に、ファームウェアやソースコードの公開先をまとめています。まず製品名で探し、各リポジトリのREADMEから対応構成と導入方法を確認してください。

**確認日：2026年10月19日。** 公開リポジトリの更新状況と[ZMK Shield Fleetの管理台帳](https://github.com/te9no/zmk-shield-fleet/blob/main/users/te9no/fleet.toml)を確認して整理しています。メンテナンス対象であることと、すべての構成が実機検証済みであることは別です。

## メンテナンス対象のキーボード・モジュール

共通変更や検証状況をZMK Shield Fleetで追跡している、サイト掲載製品のリポジトリです。製品名が似ていても、別モデルのファームウェアは流用しないでください。

### GeaconEquinox

- [zmk-keyboard-GeaconEquinox](https://github.com/te9no/zmk-keyboard-GeaconEquinox) — GeaconEquinoxのZMKファームウェア。US／JIS配列と左右の構成を確認できます。
- [ビルドガイド](../25geaconequinox/)

配布元では実機検証が未完了と案内されています。導入前に[ファームウェアの案内・検証状況](https://github.com/te9no/zmk-keyboard-GeaconEquinox/blob/HEAD/docs/firmware.md)を確認してください。

### GeaconPolaris

- [zmk-config-GeaconPolaris](https://github.com/te9no/zmk-config-GeaconPolaris) — GeaconPolarisの設定とビルド構成。左右と搭載モジュールに対応するものを選びます。
- [ビルドガイド](../20geaconpolaris/)

### SparAkashaAnanta

- [zmk-config-SparAkashaAnanta](https://github.com/te9no/zmk-config-SparAkashaAnanta) — Anantaの設定とビルド構成。左右・モジュールの組み合わせを確認できます。
- [ビルドガイド](../22sparakashaananta/)

### CornixTP・Madula

- [zmk-keyboard-cornix](https://github.com/te9no/zmk-keyboard-cornix) — Cornix左右と、CornixTP／Madulaの親機を組み合わせるZMKファームウェア。
- [CornixTPビルドガイド](../23cornixtp/) · [Madulaビルドガイド](../24madula/) · [ファームウェアの選び方](../../cornix-firmware/)

親機と左右の子機では書き込むファイルが異なります。通常版と設定を消す復旧版も区別してください。

### MeKaBu（Futhesia Moduora）

- [zmk-config-MKB2](https://github.com/te9no/zmk-config-MKB2) — MeKaBuのZMK設定。使用するモジュールとブランチごとの案内を確認してください。
- [製品比較・選び方](../../test/choose/)

### GeaconSolstice（過去モデル）

- [zmk-config-GeaconSolstice](https://github.com/te9no/zmk-config-GeaconSolstice) — SolsticeのZMK設定。過去モデルですが、Fleetの管理対象に含まれています。
- [ビルドガイド](../32geaconsolstice/)

## 便利ツール・サイト

### ZMK Helper Android

[ZMKHelperAndroid](https://github.com/te9no/ZMKHelperAndroid) — Androidからファームウェアの取得・書き込みを行うアプリ。APKと対応機器、導入手順はREADMEを参照してください。

### ZMK Shield Fleet

[zmk-shield-fleet](https://github.com/te9no/zmk-shield-fleet) — 複数のキーボードにまたがる変更と検証状況を管理するツール。[ダッシュボード](https://te9no.github.io/zmk-shield-fleet/)から、各製品の対応状況を確認できます。

### Narehate Playground

[NarehatePlayground](https://github.com/te9no/NarehatePlayground) — このサイトのソースコード。ビルドガイドや製品選びのページを管理しています。

配列エディターの[Forma](https://klemodern.netlify.app/)は利用ページを案内しています。公開ソースの所在を確認できていないため、リポジトリのリンクは掲載していません。

## ファイルを取得する前に

1. **機種・基板・モジュール構成を合わせる。** 同じリポジトリに複数の構成が含まれる場合があります。
2. **READMEで対象ブランチを確認する。** 開発用ブランチと通常配布用のファイルを混同しないでください。
3. **ビルド成功と実機確認を区別する。** 新しい更新日時だけで、手元の構成に対応しているとは限りません。
4. **配布方法を確認する。** ファイルはREADMEで案内されている場所から取得します。GitHub Actionsの成果物は保存期限がある場合があります。

書き込みの基本操作は[ファームウェアガイド](../90firmwareguide/)を参照してください。
