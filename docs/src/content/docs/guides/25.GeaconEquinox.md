GeaconEquinoxの基板とケースの組み立て手順です。**基板上のLEDとリセットボタンはPCBA済みです。** ケース側の操作部品はケース編で取り付けます。

## 作業を始める前に

- はんだ付けやケーブルの抜き差しは、**USBと電池の両方を外して**行います。
- 基板の左右・表裏は、USB端子と切り欠きを目印にします。

はんだごて、はんだ、ピンセット、作業マット、拡大鏡などを用意します。接合部の確認にはテスターもあると便利です。

## 1. 基板の小型部品を取り付ける

写真の構成では、左右のメインPCB、XIAO、電池端子、キースイッチソケット、センサーモジュールとFFCケーブルを使用します。スイッチ、キーキャップ、ケースなどは購入した構成に合わせて用意してください。

小型部品は部品表の番号に合わせて取り付けます。

1. 基板の部品番号と取り付け面を確認し、対応する部品を用意します。極性や1番ピンのある部品は、部品と基板のマークを合わせます。
2. 取り付け位置のパッド1か所に少量の予備はんだを載せます。
3. ピンセットで部品を置き、予備はんだを溶かして仮止めします。
4. 位置と向きを確認し、残りの端子をはんだ付けします。多ピン部品は各端子が対応するパッドに合っていることを確認してから進めます。
5. 拡大して、浮き、はんだ不足、隣の端子とのブリッジがないか確認します。

基板端のU2と周辺部品の取り付け例です。

![基板端のU2と周辺部品の接写。小型部品の位置を確認する](./GeaconEquinox/01-onboard-component-detail.jpg)

## 2. XIAOと周辺部品を取り付ける

左右それぞれに**Seeed Studio XIAO nRF52840 Plus**を取り付けます。USB端子は基板の外周側を向きます。続いて電源スイッチと昇圧基板を取り付けます。

### XIAOの取り付け

1. XIAOの輪郭とUSB端子の位置を基板に合わせ、各端子が対応するパッドに重なるように置きます。
2. 端の端子を1か所仮止めし、位置ずれや傾きがないか確認します。
3. 位置が決まったら、接続対象の端子を順にはんだ付けします。基板側のパッドとXIAO側の端子の両方にはんだがなじむようにします。
4. 裏面は、接続パッドをはんだ付けします。

### 電源スイッチの取り付け

1. 電源スイッチを基板の穴・パッドに合わせて置き、浮きがない状態で仮止めします。
2. 位置を整え、残りの端子と固定用の端子をはんだ付けします。

![左右のXIAOと電源スイッチの取り付け例。LEDとリセットボタンはPCBA済み](./GeaconEquinox/02-xiao-and-leds.jpg)

### 昇圧基板の取り付け

裏面の昇圧基板は、**電源スイッチの足を避けるため、写真のように少し斜めに取り付けます。**

1. 昇圧基板の接続端子を取り付け位置に合わせ、電源スイッチの足に当たらないよう、少し斜めに配置します。
2. 端子1か所を仮止めし、写真と照合しながら位置を調整します。
3. 接続端子が対応するパッドに合っていることを確認し、残りをはんだ付けします。

![左右の基板裏面。昇圧基板は電源スイッチの足を避けて少し斜めに取り付ける](./GeaconEquinox/07-controller-back.jpg)

## 3. 電池端子を取り付ける

1. 写真を参考に、基板の内側の切り欠きに沿って端子を配置します。
2. 片側を仮止めし、端子の傾きや浮きを整えます。
3. 残りをはんだ付けし、冷めるまで端子を動かさずに待ちます。

![左右それぞれの上下の電池端子。基板の極性表示も確認する](./GeaconEquinox/03-battery-contacts.jpg)

横から見た端子の位置は、下の写真を参考にしてください。

![基板の縁に取り付けた電池端子を横から見た状態](./GeaconEquinox/04-battery-contact-side.jpg)

## 4. キースイッチソケットを取り付ける

**使用する配列によって、はんだ付けするソケットの位置が変わります。** 基板の印字・穴位置と写真を見比べ、キーごとに位置と向きを合わせます。

1. ソケットを基板に置き、スイッチのピンが通る穴とソケットの差し込み口を合わせます。
2. 一方の端子を仮止めします。
3. ソケットが基板に密着していることを確認し、もう一方をはんだ付けします。
4. 仮止めした側も確認し、未接合や浮きがあれば直します。

## 5. センサーモジュールを組み立てて接続する

### センサーとコネクタの取り付け

1. センサーをモジュール基板の印字と端子位置に合わせて置きます。向きは部品のマークと基板の表示で確認してください。
2. 端子1か所を仮止めし、位置と傾きを整えてから残りをはんだ付けします。隣り合う端子をはんだでつながないようにします。
3. FFCコネクタを対応するパッドに合わせ、ケーブルの差し込み口の向きを確認して取り付けます。固定用の端子で位置を決めてから、信号端子をはんだ付けします。メインPCB側も同様に作業します。
4. 接合部を拡大して確認します。コネクタの樹脂やロック部分にこて先を当てず、差し込み口にはんだを流さないでください。

### FFCケーブルの接続

FFCケーブルでメインPCBとセンサーモジュールをつなぎます。ケーブルの接点面をコネクタの接点に向けて差し込みます。

1. コネクタのロック方式を確認します。ロックがある場合は、指定された方向に解除します。
2. ケーブルを斜めにせず、左右均等に奥まで差し込みます。
3. ロックを戻し、ケーブルが片側だけ抜けていないことを確認します。
4. 反対側も同様に接続します。

![メインPCBからセンサーモジュールへ接続したFFCケーブルの経路](./GeaconEquinox/05-sensor-ffc-routing.jpg)

モジュールは基板の縁を持ち、レンズ面には触れないようにします。ケーブルには余裕を持たせます。

![接続したセンサーモジュールの接写。FFCの差し込みと余裕を確認する](./GeaconEquinox/06-sensor-module-detail.jpg)

## 6. ケース編：底板にプレートを固定する

使用するねじは **FLA-0305E**、ナットは **M3** です。樹脂部品が変形しない程度に締めます。

1. 底板と刻印があるプレートの穴位置を合わせます。刻印はケースの外側に向けます。
2. 外側からねじを通し、内側に写真の固定部品を配置します。固定部品はプレートの両端に1個ずつ使います。
3. 内側の写真を参考に、各固定部品の3か所へナットを合わせます。すべてを仮止めしてから、位置ずれがないことを確認して少しずつ締めます。

## 8. ケース編：ノブを取り付ける

ノブ本体、四角い取り付け部品、固定ねじを用意します。

![左からノブ本体、四角い取り付け部品、固定ねじ。ノブの裏面中央に金属のねじ穴がある](./GeaconEquinox/18-knob-parts.jpg)

1. ノブ裏面のねじ穴と、取り付け部品の中央の穴を合わせます。
2. 取り付け部品の裏側からねじを通し、ノブを留めます。

![ノブを取り付け部品に組み付けた裏側。中央の黒いねじでノブを留めた状態](./GeaconEquinox/19-knob-rear-screw.jpg)

3. 組み立てたノブを、上側ケースの対応する四角い開口部に合わせて取り付けます。
4. 写真のようにノブが表側に出ていることを確認し、指で回して周囲に引っ掛からないか確かめます。

![上側ケースの四角い開口部に取り付けたノブ。表側にノブが出ている状態](./GeaconEquinox/20-knob-installed.jpg)

## 9. ケース編：電源スイッチとリセットボタンの操作部品を取り付ける

上側ケースを裏返し、電源スイッチとリセットボタン用の操作部品を取り付けます。

1. 丸形の電源スイッチ用部品と、長方形のリセットボタン用部品を、それぞれの取り付け位置に置きます。
2. 電源スイッチ用部品は、中央の穴を合わせて差し込みます。
3. 基板を合わせ、操作部品の位置と動きを確認します。リセットボタンが押されっぱなしにならないようにします。

## 10. ケース編：バックルを取り付ける

バックルには **FF-0304E** のねじを使います。

1. バックルの内側から中央の穴へねじを入れます。

<div class="landscape-photo">

![バックルと取り付け用ねじ。ねじの品番表示はFF-0304E](./GeaconEquinox/14-case-buckle-parts.jpg)

</div>

2. ねじ頭を中央のくぼみに収めます。

![バックルの中央にねじを入れ、内側のくぼみにねじ頭が収まった状態](./GeaconEquinox/15-case-buckle-screw.jpg)

3. 上側ケースと底板の位置を合わせ、下の写真を参考にケース側面へバックルを取り付けます。
4. バックルの縁をケースに掛けます。掛からないときは、無理に広げずケースの位置ずれやケーブルの挟み込みを直します。

![ケース側面に取り付けたバックル。ケースの縁に掛かる位置を確認する](./GeaconEquinox/16-case-buckle-installed.jpg)

**ケースを閉じるときは、FFCケーブルを縁やねじに挟まないように収めます。**

## 11. ケース編：バッテリーカバーを組み立てる

写真の左が組み立て前、右が組み立て例です。使用するねじの品番は **FLA-0305E** です。

1. スリットのあるカバーのねじ穴側に、細長い部品を重ねます。
2. 両端の穴を合わせ、写真右のようにカバー側からねじを入れて固定します。

![バッテリーカバー。左はカバーと細長い部品、右は両端をねじで固定した組み立て例。ねじの品番はFLA-0305E](./GeaconEquinox/17-case-battery-cover.jpg)

## 12. 通電前のチェック

- はんだのブリッジ、金属くず、部品同士の意図しない接触がない。
- FFCが奥まで入り、ケースに挟まれていない。
- 電源スイッチとリセットボタンが動き、バックルが掛かっている。
- 電池の種類・電圧・極性が指定どおりになっている。

通電後に異常な発熱や異臭があれば、USBと電池を外してください。

## ファームウェアと動作確認

[GeaconEquinoxのリポジトリ](https://github.com/te9no/zmk-keyboard-GeaconEquinox)から、構成に合うファームウェアを用意し、左右それぞれに書き込みます。

書き込みの基本的な流れは[ファームウェアガイド](../90firmwareguide/)を参照してください。

組み立て後は、左右すべてのキーとセンサーの入力を確認します。

- キーが反応しない：電源を外し、スイッチのピン曲がり、ソケットの浮き、はんだ付けを確認します。
- センサーが反応しない：ファームウェアの構成とFFCの接続を確認します。
